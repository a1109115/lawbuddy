## 阅读提示

部分文档保留了项目内部的需求编号与里程碑代号（如 `REQ-DOC-004`、`DEC-004`、`O-015`、`M3` / `M4`）。这些编号来自内部开发清单，公开仓库中没有对应清单，可按以下含义理解：

| 前缀 | 含义 |
| --- | --- |
| `REQ-*` | 功能需求条目 |
| `DEC-*` | 已决策事项（含理由与替代方案） |
| `O-*` | 待办优化项 |
| `M2` / `M3` / `M4` / `M5` | 里程碑阶段；对应评测脚本见 `services/core/evals/` 中 `m2_*` / `m3_*` / `m4_*` / `m5_*` |
| `S-*` | 安全评测项，见 `services/core/evals/m3_security.py` |
| `DEV-MOD-*` / `G-*` | 开发模块与验收目标编号 |
