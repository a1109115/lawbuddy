# 民事案由体系概览

本书以 2020 年《民事案件案由规定》为体系基础，结合《民法典》《民事诉讼法》及最新司法解释，按照三级/四级案由结构编排。全书分上、下两册，共十大部分。

## 使用说明

1. 每个第三级案由下均设【案由适用要点】和【请求权基础规范指引】两个栏目。
2. 【案由适用要点】包含释义、管辖、应注意的问题三方面内容。
3. 【请求权基础规范指引】从诉讼请求出发列明现行法律依据，条文更新至 2024 年 11 月。
