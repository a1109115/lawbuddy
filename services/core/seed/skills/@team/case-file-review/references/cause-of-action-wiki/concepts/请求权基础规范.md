# 请求权基础规范

请求权基础规范是本书每个第三级案由下设置的第二个栏目。本书引入请求权基础规范理论，从当事人的诉讼请求出发，列明该请求权的现行法律依据，便于法官和当事人在择定案由后立即查阅必需的法律适用根据。

该栏目所列条文包括近年来新颁布实施的重要法律法规、司法解释、司法政策等，并特别标注规范文本的公布或修订、修正时间。文本更新截至 2024 年 11 月。
