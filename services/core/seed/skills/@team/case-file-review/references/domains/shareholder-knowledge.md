# 股东知情权专属争点（references/domains/shareholder-knowledge.md）

- **适用案由**：股东知情权纠纷（案由知识库 267 号，第四级子项也回退本页+父级）
- **触发信号**：诉请涉及查阅/复制财务会计报告、会计账簿、会计凭证、章程、股东会/董事会/监事会记录
- **新旧条号对照（重要）**：2018 修正《公司法》旧 33 条 → 2023 修订新 57 条；旧 97 条 → 新 110 条。**2024-07-01 前立案的案子适用旧法**——旧法第33条未列举"会计凭证"，这是被告核心抗辩点之一，勿用新法条号倒推
