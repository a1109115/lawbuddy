# 建设工程专属争点与阅卷检测要点

当 `case-file-review` 识别到案由为「建设工程施工合同纠纷」时，在从**案由知识库**调取该案由的【请求权基础规范】做要件拆解之外，加载本参考，主动扫描以下建工专属争点。本文件不做要件罗列（要件从案由知识库取），只处理**横在要件之上的实体法律问题**——这些是建工案高频败诉点和质证突破口，通用阅卷框架容易漏掉。

每条给出：争点定义 → 关联法条（具体条号）→ 阅卷要提取的事实与证据 → 常见红旗/矛盾点。

> **类型**：专有 domain 参考（案由 = 建设工程施工合同纠纷时由 SKILL.md 路由加载，可插拔）。存放于 `references/domains/`，属「参考文档分类约定」中的 domain 类。

> ⚠️ **法律更新提示**：《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（二）》（法释〔2026〕12号）已于 **2026年6月30日** 施行，第23条明确"本解释施行后，最高人民法院以前发布的司法解释与本解释不一致的，以本解释为准"。本参考相关争点已同步标注（一）/（二）条文；**2026-06-30 后新受理的一审案件优先适用（二）**。阅卷时应注意区分新旧解释，对解除/退场、挂靠突破相对性等新增规则尤其敏感。

## 1. 实际施工人 / 挂靠 / 转包 / 违法分包

**争点本质**：建工领域普遍存在的资质借用与层层转包。它直接影响「谁有资格主张工程款」「谁应对质量缺陷负责」「欠付工程款的责任边界」。

**关联法条**
- 民法典第791条第3款：禁止承包人将工程分包给不具备相应资质的单位；禁止分包单位再分包；主体结构必须由承包人自行完成。
- 《建工解释一》第1条第(二)项：没有资质的实际施工人借用有资质的建筑施工企业名义（挂靠）→ 合同无效。
- 《建工解释一》第7条：出借资质方与借用方对工程质量不合格等损失承担连带赔偿责任。
- 《建工解释一》第43条：实际施工人以发包人为被告主张权利的，发包人仅在**欠付工程款范围内**对实际施工人承担责任（突破合同相对性的例外）。
- 《建工解释一》第44条：实际施工人可依据民法典第535条提起代位权诉讼。
- **《建工解释二》第3条**（2026-06-30施行）：出借资质/允许他人以本企业名义承揽工程→合同无效；出借方主张资质借用费/使用费的，不予支持；质量合格时借用方参照其与出借方关于工程款的约定请求折价补偿。
- **《建工解释二》第4条**：资质借用、发包人订立合同时**不知情**的，借用方以合同直接约束发包人为由请求发包人支付的，不予支持；发包人**知情**的，法院可判发包人向借用方承担责任（并通知出借方作为第三人）。
- **《建工解释二》第7条**：借用资质方/接受转包或违法分包方，可依据民法典第535条代位权向发包人主张。

**阅卷要提取**
- 总包合同乙方、现场实际施工主体、付款流向（是否直接付给个人/第三方）
- 是否存在「内部承包协议」「挂靠协议」「管理费」约定
- 项目经理/项目负责人与合同主体的劳动关系证明
- **发包人是否知晓资质借用**（决定能否直接主张发包人付款，见解释二第4条）

**常见红旗**
- 合同乙方（有资质单位）收取固定"管理费"但不实际施工 → 挂靠嫌疑
- 发包人付款直接打给个人或多层下游 → 转包/违法分包链条
- 证据清单里只有总包合同、没有实际施工关系证据 → 原告若系实际施工人，证据链缺口
- 挂靠情形发包人知情 → 可绕过合同相对性直接主张（解释二第4条新路径）

## 2. 黑白合同 / 实质性内容背离

**争点本质**：强制招标项目或已招标项目，当事人另签一份与中标合同在工程范围、工期、质量、价款等**实质性内容**不一致的合同。

**关联法条**
- 招标投标法第46条：中标通知书发出之日起30日内订书面合同，不得再订背离实质性内容的其他协议。
- 《建工解释一》第2条：另行签订合同与中标合同实质性内容不一致 → 以中标合同为结算依据。
- 《建工解释一》第22条：合同与招标文件、投标文件、中标通知书载明的工程范围/工期/质量/价款不一致 → 以招标文件等作为结算依据。
- 《建工解释一》第23条：非必须招标但已招标的，亦按中标合同结算。
- 《建工解释一》第24条：数份合同均无效但质量合格 → 参照**实际履行**合同折价补偿。
- **《建工解释二》第2条**（2026-06-30施行）：在确定中标人前就实质性内容谈判且该投标人中标，或先协商订立合同再通过招投标订立合同的，依招投标法认定中标合同无效（串标/先行谈判）。

**阅卷要提取**
- 中标通知书、招标文件、投标文件中的价款/工期/质量
- 备案合同（白合同）与实际履行合同（黑合同）的价款差异
- 实际履行中按哪份合同付款、签证、结算
- **是否存在中标前谈判/串标线索**（解释二第2条新情形）

**常见红旗**
- 两份合同价款差异巨大，且结算按黑合同走 → 原告主张按白合同结算时被告抗辩
- 证据中只有一份合同，但对方主张存在另一份 → 证据缺口，需提示当事人补充
- 中标前已就实质性内容谈判 → 中标合同本身可能无效（解释二第2条）

## 3. 建设工程价款优先受偿权

**争点本质**：承包人的工程款债权优先于抵押权和其他普通债权；但**有严格期限和范围限制**，过期即丧失。

**关联法条**
- 民法典第807条：发包人逾期不支付价款，除工程性质不宜折价拍卖外，承包人可折价/拍卖并就价款优先受偿。
- 《建工解释一》第35条：与发包人订立合同的承包人可主张优先受偿。
- 《建工解释一》第36条：优先受偿权**优于抵押权和其他债权**。
- 《建工解释一》第38条：工程质量合格即可主张，**不以合同有效为前提**。
- 《建工解释一》第39条：未竣工但质量合格，可就承建部分优先受偿。
- 《建工解释一》第40条：优先受偿范围限于**工程价款本身**；逾期付款利息、违约金、损害赔偿金**不**优先受偿。
- 《建工解释一》第41条：应在合理期限内行使，**最长不超过十八个月**，自发包人应当给付建设工程价款之日起算。
- 《建工解释一》第42条：约定放弃/限制优先受偿权，若损害建筑工人利益，该约定无效。
- **《建工解释二》第21条**（2026-06-30施行）：优先受偿权行使期限起算点细化——因工期顺延等客观原因协商变更给付日期的，自变更后日期起算；未约定/约定不明但结算协议明确约定给付日的，自该日起算。

**阅卷要提取**
- 发包人「应当给付工程款」之日（合同付款节点 / 结算确认日 / 起诉日）
- 承包人主张优先受偿的时点，是否超过18个月
- 工程是否「不宜折价拍卖」（如公益设施、军事工程）
- 欠款构成中利息/违约金占比（这些不在优先受偿范围）
- **工期顺延/结算协议是否变更了给付日**（解释二第21条影响起算点）

**常见红旗**
- 起诉/主张优先受偿时距应付日已超18个月 → 权利可能消灭（被告核心抗辩）
- 原告清单把利息、违约金也计入优先受偿数额 → 需剥离，仅本金部分优先
- 被告以「已放弃优先受偿权」抗辩 → 核实是否损害建筑工人利益
- 存在工期顺延签证或结算协议 → 优先受偿起算点可能相应后移（解释二第21条）

## 4. 工期认定与工期顺延

**争点本质**：开工日、竣工日如何认定，直接决定逾期竣工违约金、工期顺延是否成立。

**关联法条**
- 《建工解释一》第8条：开工日期争议——(一)开工通知载明的日期（尚不具备条件的以具备日为开工日）；(二)经发包人同意实际进场施工的，以实际进场日；(三)无通知无证据的，综合开工报告、合同、施工许可证、竣工验收报告等认定。
- 《建工解释一》第9条：实际竣工日争议——(一)竣工验收合格日；(二)发包人拖延验收的，以承包人提交验收报告日；(三)发包人擅自使用的，以转移占有日。
- 《建工解释一》第10条：发包人未按约定提供原材料、设备、场地、资金、技术资料，承包人可顺延工期并请求赔偿停窝工损失（需有签证等证明）。
- 《建工解释一》第14条：发包人擅自使用的法律后果（见争点8）。
- 民法典第798条：发包人未按时提供场地的，承包人可顺延工期并索赔。

**阅卷要提取**
- 开工通知日期 vs 实际进场/开工报告日期
- 竣工报告提交日、验收合格日、发包人实际使用日
- 工期顺延签证、停窝工损失证据（现场签证、监理确认）

**常见红旗**
- 合同工期起算（开工通知）与实际进场日相差数月，且无顺延签证 → 逾期天数认定争议
- 发包人已实际使用工程但主张"未验收合格"拒付 → 依第9条第(三)项/第14条视为合格

## 5. 质量缺陷责任期 vs 保修期（质保金）—— 当前案件重点

**争点本质**：这是建工案最高频的混淆点，直接决定**质保金是否应当返还**。二者是不同概念，常被发包人混用拒付。

**概念区分**
- **质量缺陷责任期（Defect Liability Period）**：合同约定的扣留质保金的期限，一般为1年，最长不超过2年（建质〔2017〕138号第2条）。缺陷责任期内出现缺陷，用质保金修复；期满无质量问题即返还质保金。
- **保修期（Warranty Period）**：法定最低期限（质量条例第40条），自竣工验收合格起算，如屋面防水工程5年、电气管线/给排水/设备安装/装修工程2年、地基基础和主体结构为设计使用年限。保修期通常**长于**缺陷责任期。

**关联法条**
- 《建工解释一》第17条：有下列情形之一，承包人请求返还质保金的应予支持：(一)约定的质保金返还期限届满；(二)未约定返还期限的，自竣工验收合格之日起满**二年**；(三)因发包人原因未按期竣工验收的，自承包人提交验收报告九十日后起算（满约定期限或满二年）。**第17条末款明确：发包人返还质保金后，不影响承包人依法承担保修责任（返还≠免除保修义务）**。
- 建设工程质量保证金管理办法（建质〔2017〕138号）第2条：缺陷责任期最长不超2年；第7条：质保金预留比例不得高于结算总额3%；第8条：缺陷责任期自工程通过竣工验收之日起计。
- 建设工程质量管理条例第40条：法定最低保修期限。
- **《建工解释二》第14条**（2026-06-30施行，本案高度相关）：建设工程施工合同**解除**的，承包人主张预留质保金以其**应得工程价款**为基数计算的，应予支持；**质保金返还期限从承包人退场之日起算**；施工合同在退场后解除的，从解除之日起算。合同无效且工程未完工的，同理，返还期限从退场之日起算。

**阅卷要提取（针对质保金返还请求）**
- 合同约定的质保金比例、返还条件、返还时点
- 竣工/验收合格日期（起算点）
- 缺陷责任期 vs 保修期的分别约定（很多合同把两者混写）
- 发包人主张拒还的理由：是"缺陷责任期未到"还是"保修期未到"
- **本案是否涉及合同解除/退场**（若是，返还起算点适用解释二第14条"从退场之日起算"，而非竣工验收合格满二年）

**常见红旗（原告视角必查）**
- 发包人以"保修期（如5年）未届满"拒还质保金 → **法律上不成立**，质保金看缺陷责任期/约定返还期，与保修期无关（第17条末款）。阅卷时应主动批注此抗辩不成立。
- 合同只写"保修期满返还"未区分缺陷责任期 → 依第17条第(二)项，未约定返还期限的自竣工验收合格满二年返还。
- 质保金金额 > 结算总额3% → 超出部分约定可能不当（建质〔2017〕138号第7条）。
- 本案合同已解除/承包人已退场 → 质保金返还起算点应适用**解释二第14条从退场之日起算**，勿机械套用"竣工验收合格满二年"。
- 金额交叉校验：质保金金额应≈合同金额×质保金比例；请款金额应≈合同金额−质保金（不符则红字标注）。

## 6. 工程量与工程造价认定

**争点本质**：干了多少量、值多少钱，是价款争议的核心；无书面签证时举证困难。

**关联法条**
- 《建工解释一》第19条：工程量有争议，按施工过程中形成的签证等书面文件确认；承包人能证明发包人同意其施工，虽无签证但有其他证据（会议纪要、往来函件、监理记录）证明实际发生量的，应予支持。
- 《建工解释一》第20条：工程量无签证且争议大，当事人可申请鉴定。
- **《建工解释二》第9条**（2026-06-30施行）：固定价合同，当事人以工期内人工/主要材料价格重大变化请求调价的不予支持，但另有约定或符合民法典第533条情势变更的除外。
- **《建工解释二》第10条**：固定总价合同解除后，已施工部分价款约定不明且不能协商一致的，可参照当地建设行政主管部门计价标准/方法确定已施工部分占全部工程价款比例，以该比例×固定总价确定。
- **《建工解释二》第11条**：民法典第793条第1款"参照合同关于工程价款的约定"，包括金额、计价方式、支付时间、调整方法、结算方法等。
- **《建工解释二》第12条**：合同无效但质量合格，发承包就折价补偿款达成协议的，依协议确定；转包/违法分包情形下参照处理。

**阅卷要提取**
- 签证单、工程联系单、洽商记录（是否有发包人/监理签字确认）
- 工程量清单、竣工图、结算书
- 双方无争议部分 vs 有争议部分（争议部分可能需鉴定）
- **固定价合同是否约定调价/情势变更条款**（解释二第9条）

**常见红旗**
- 大量增项工程量无签证、无签认 → 原告举证缺口，被告可否认
- 结算书单方制作无对方确认 → 证明力弱，需其他证据补强
- 固定总价合同解除 → 已完工价款可能按解释二第10条"比例法"确定，而非原告主张的全额

## 7. 合同效力瑕疵

**争点本质**：建工合同无效情形多，但无效不必然导致承包人丧失价款请求权（质量合格即可参照约定折价补偿）。

**关联法条**
- 《建工解释一》第1条：无效情形——(一)承包人无资质或超越资质；(二)无资质实际施工人借用资质（挂靠）；(三)应招标未招标或中标无效。
- 《建工解释一》第4条：超越资质但在竣工前取得相应资质的，不按无效处理。
- 《建工解释一》第3条：未取得建设工程规划许可证等规划审批手续的，合同无效；但起诉前取得的除外。
- 民法典第793条：无效但验收合格的，可参照合同关于工程价款的约定折价补偿。
- **《建工解释二》第1条**（2026-06-30施行）：订立时属于必须招标的工程项目，当事人未经招标订立合同，但**起诉时该工程不再属于必须招标的**，不唯未招标认定无效。
- **《建工解释二》第3条**：出借资质/允许他人以本企业名义承揽工程→合同无效；出借方主张借用费不支持；质量合格时借用方参照约定请求折价补偿。

**阅卷要提取**
- 承包人建筑业企业资质证书及等级、签订合同时是否在有效期内
- 是否属于必须招标项目、是否履行了招标；**起诉时是否仍属必须招标**（解释二第1条新标准）
- 规划许可证取得时点（是否起诉前取得）

**常见红旗**
- 承包方资质等级低于工程要求 → 合同可能无效，但质量合格仍可主张价款（提醒当事人效力不影响主请求）
- 应招标项目未招标 → 黑白合同规则与无效规则叠加
- 资质借用 → 合同无效且借用费不受保护（解释二第3条）

## 8. 发包人擅自使用视为验收合格

**争点本质**：发包人未验收即占有使用工程，法律拟制为验收合格，反向推定为质量合格（地基基础和主体结构除外）。

**关联法条**
- 《建工解释一》第14条：建设工程未经竣工验收，发包人擅自使用的，以转移占有建设工程之日为竣工日期；且发包人使用后又以使用部分质量不符合约定为由主张权利的，不予支持，但承包人应在合理使用寿命内对地基基础和主体结构质量承担民事责任（第14条含两款：竣工日认定 + 质量异议限制）。
- 民法典第799条第3款：建设工程竣工经验收合格后，方可交付使用；未经验收或验收不合格的，不得交付使用。

**阅卷要提取**
- 发包人实际入驻/营业/使用工程的证据（照片、物业记录、营业许可日期）
- 使用时点 vs 验收合格时点的先后

**常见红旗**
- 发包人已使用却以"未验收合格"拒付工程款 → 依第14条视为合格，抗辩不成立
- 使用后发现质量问题主张拒付 → 一般质量部位不支持，但地基/主体结构承包人仍负责
